# Schematics

This folder contains schematic capture files and related design materials.

## Typical contents

- main schematic
- sub-circuit sheets
- power distribution sheets
- connectivity diagrams
- revision notes

## Naming convention

Use clear names such as:
- main_schematic.sch
- power_management.sch
- interface_connectivity.sch

## Checklist

- power rails reviewed
- grounding strategy defined
- connectors labeled
- signals net-named consistently
- key test points added
