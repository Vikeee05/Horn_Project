# Bill of Materials

This folder stores the part list and sourcing information for the hardware design.

## Contents

- BOM spreadsheet
- component references
- manufacturer and part numbers
- quantity and cost tracking
- alternate part options

## Required columns

- Reference designator
- Description
- Quantity
- Manufacturer
- Manufacturer part number
- Supplier
- Unit cost
- Notes

## Review checklist

- all schematic references accounted for
- package types verified
- tolerances reviewed
- availability checked
- alternate sources listed where needed
