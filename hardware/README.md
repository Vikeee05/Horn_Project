# Hardware Design

This folder contains the hardware design assets for the project.

## Structure

- docs/ — design requirements, notes, and specifications
- schematics/ — schematic capture files and design notes
- pcb/ — PCB layout, gerber outputs, and related board files
- bom/ — bill of materials and component list
- libraries/ — custom or imported symbols, footprints, and libraries

## Purpose

This workspace is intended for:
- system architecture and hardware requirements
- schematic capture
- PCB layout and routing
- component selection and BOM management
- review and revision tracking

## Recommended workflow

1. Define requirements in docs/
2. Create the schematic in schematics/
3. Design the PCB in pcb/
4. Validate the BOM in bom/
5. Review all files before fabrication

## Notes

- Keep all design decisions documented.
- Maintain revision tracking for each major change.
- Use consistent naming for files and assemblies.
