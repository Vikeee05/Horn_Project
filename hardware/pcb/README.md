# PCB Layout

This folder contains PCB design files and manufacturing outputs.

## Typical contents

- board layout files
- routing revisions
- copper layer outputs
- mechanical keep-outs
- manufacturing notes

## Checklist

- component placement reviewed
- routing clearance checked
- thermal paths considered
- EMI/EMC concerns reviewed
- silkscreen labels verified
- assembly notes recorded

## Output files to prepare

- PCB layout source
- Gerber files
- drill files
- pick-and-place data
- fabrication notes
